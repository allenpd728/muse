# Test spec — W1 event-stream IR

**Task:** #123 (W1 — Event-stream IR)
**Written:** 2026-08-23

## What to verify

1. **Model invariants**
   - Negative duration rejected; pitch outside [-2, 127] rejected; velocity
     outside [0, 127] rejected
   - Maps (tempo/meter/key) validated for tick ordering
   - Notes sorted deterministically by (onset, pitch, voice)
   - `is_rest` / `is_unpitched` properties behave (pitch -1 / -2)

2. **MusicXML parser**
   - .xml and .mxl (zip) both parse
   - Tied notes preserved as separate events with tie_start/tie_stop flags
   - Rests included as pitch=-1 events
   - Unpitched percussion included as pitch=-2 events
   - Full part list preserved (52 parts on Beethoven 9)

3. **MIDI parser**
   - note_on/note_off pairing correct; overlapping same-pitch notes handled
     (FIFO)
   - Tempo/meter/key maps extracted from meta events
   - Missing tempo map produces warning, not crash
   - Velocity preserved where present

4. **Known-answer conformance** (the gate)
   - `python3 tools/muse_ir/conformance.py` — all 13 corpus cases pass
   - Malformed input (e.g., corpus/README.md) rejected with ValidationError

5. **Edge cases**
   - Empty part (no notes) — allowed, part still listed
   - Zero-duration note (grace-note-like) — allowed
   - File with unsupported extension — ValidationError

## How to run

```bash
pip install partitura mido
python3 tools/muse_ir/conformance.py
```
