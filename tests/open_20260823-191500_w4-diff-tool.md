# Test spec — W4 diff tool

**Task:** #126 (W4 — Diff tool)
**Written:** 2026-08-23

## What to verify

1. **Engine correctness**
   - Self-diff on any corpus work = recall 1.0, precision 1.0
   - Greedy pairing is deterministic (same inputs → same report, always)
   - Rests (pitch=-1) and unpitched (pitch=-2) participate in matching

2. **Mutation behavior** (self-test in cli.py)
   - Deletion degrades recall < 1.0
   - Insertion degrades precision < 1.0
   - Onset drift within tolerance → classified "onset-drift", not missing/extra
   - Velocity mismatch (both velocities present) → "velocity-drift"

3. **Tolerance semantics**
   - tolerance=0: exact tick equality only
   - tolerance>0: |onset_a − onset_b| ≤ tolerance matches

4. **CLI**
   - Exit 0 when reports.ok(), exit 1 otherwise (CI gate behavior)
   - Report prints recall/precision/matched counts; mismatch list (first 20)

## How to run

```bash
python3 tools/muse_diff/cli.py --self-test
python3 tools/muse_diff/cli.py <file_a> <file_b> [--tolerance-ticks N]
```
