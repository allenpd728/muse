## Behaviors to verify

- **Demo WAV freshness:** `docs/demo/*.wav` are regenerable byte-identically
  from the committed pipeline (deterministic) — pin a checksum guard, or
  accept drift and pin only the README's regenerate command. Decision left
  to implementer; checksums break on any DSP tweak.
- **Live-model end-to-end:** `MUSE_MODEL`-configured play path (LLM
  expansion → same WAV pipeline) — manual smoke, never CI; record a fixture
  when first run.
- **Form coverage beyond excerpt:** `--bars` truncation is a demo feature;
  pin that full-order play of `examples/full.muse.json` completes (it does —
  ~115s WAV, verified at authoring) without memory/time blowup.
- **Imported docs:** play an importer-produced file
  (`importer/cli.mjs importer/fixtures/bwv269.mxl`) end-to-end — the
  pipeline's second source of .muse.json docs.
- **Rendition-less documents:** `examples/minimal.muse.json` play path
  (implicit default rendition) — the offline expander handles zero-form
  docs; pin silence-vs-error behavior.

## How to run

`npm test`; live smoke + full-length render documented in the closing note.

## Resolution

Residual coverage landed in `tests/play-residual.test.mjs` (issue #68):
`--bars` excerpt completes with a RIFF-header WAV; demo README regenerate
command pinned (checksums rejected per the spec's own option); imported
chorale plays end-to-end; rendition-less minimal doc plays through an
implicit default rendition (empty-notes perf doc, no crash). Two CLI bugs
found and fixed in `tools/play.mjs`: flags parsed as rendition ids for
rendition-less docs, and rendition-less docs errored instead of playing.
Live-model and full-length paths stay manual per the spec. 8/8 standalone;
npm test 47/47 green.
