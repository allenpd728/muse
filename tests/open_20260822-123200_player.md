# Test spec — Batch 3 #24: Player V1 — performance → audio

**Source task:** #24 (player/render.mjs)

DoD coverage landed with the task: `tests/player.test.mjs` — 14 checks

## Behaviors to verify

- **tempo_map interpolation:** the player currently reads note seconds
  directly (they are authoritative) and ignores tempo_map — correct, but
  pin that a doc whose tempo_map disagrees with note seconds still renders
  by note seconds (documented player behavior, see #22 follow-up's clock
  check).
- **Soundfont tier:** when a real GM soundfont ships (free tier per scope
  doc), the synth-voice fallback must remain selectable; A/B fixture: same
  perf doc renders via both engines, both non-silent, timing identical.
- **Browser entry:** Web Audio playback path (scope doc: playable
  in-browser) — out of `npm test`'s reach; verify manually at #25 demo
  time and pin the build/import path here.
- **Articulation extremes:** staccatissimo at very short durations,
  legato overlaps — no negative-time or buffer overruns (fuzz onsets/
  durations across grid values).
- **Renderer contract conformance for plugins:** a mock plugin
  implementing { id, capabilities, render } can replace the built-in
  engine — pin the call path once plugin loading exists.
- **Per-note controllers:** V1 ignores them by design; pin that their
  presence never changes V1 output (forward-compat guarantee).

## How to run

`npm test`; new suites as `tests/*.test.mjs`.
