# S3 — Seed format (design doc, scaffold)

**Phase 1 — Format spec. Status: scaffold.**

## Purpose

The prompt: sanctioned ranges, performance-philosophy fields, expression
budgets, variation points, assertions. Calibrated from delta analysis
(Vienna 4x22 et al.) — the critical-path spec. Human-authored or human-
approved; never machine-invented without review.

## Dependencies

- **Upstream:** W3 evidence + delta-analysis docs
  ([delta-analysis-plan](../delta-analysis-plan.md),
  [mockup-delta-analysis](../mockup-delta-analysis.md)).
- **Downstream:** C1 (implementation), C2/C3 (authoring), L1 (consumption).

## Scope (pin in draft)

- **Inputs:** delta-measured ranges, philosophy vocabulary.
- **Outputs:** spec section + example seed.
- **Non-goals:** a default/empty seed policy (explicitly rejected — seeds
  are authored); UI for authoring (C-series).

## Open questions

- How vocal/choral text is carried (the Ninth's finale forces this — also a
  FORMAT_SPEC §8 open question).

## Acceptance criteria (when promoted to draft)

- Spec section written; example seed validates against its own schema.
